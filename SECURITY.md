# Security policy

The latest release and default branch receive security updates. Report vulnerabilities through GitHub private vulnerability reporting. Never place credentials, personal data, or production logs in an issue.

This defensive Windows administration project does not bypass ISP limits, physical link negotiation, endpoint protection, policy, or access controls. Apply and Rollback require administrator privileges. Audit and Plan are safe defaults.

Mutating operations must stay allowlisted, reviewable with WhatIf, logged, reversible, and tested. Secrets must never be committed. Telemetry remains local unless an operator deliberately configures an approved destination.
